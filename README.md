# Terac Cookbook

Examples of agents working with human experts through Terac's MCP and API.

The first recipe, **Oracle**, will demonstrate go-to-market brief review through
clearly labeled synthetic replay, followed by verified live integration. The
calling agent decides how to use the feedback and whether to revise or continue.

The runner, replay examples, documentation and contribution checks are being
introduced through focused, reviewed pull requests. Replay will let developers
try the workflow without requesting paid expert work.

License and public-release terms are being confirmed by Terac.
