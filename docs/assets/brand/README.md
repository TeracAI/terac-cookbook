# Terac brand asset

The Terac mark comes from the [official brand page](https://terac.com/brand),
[icon-blue.svg](https://terac.com/brand/icon-blue.svg), retrieved 20 October 2026.
The original bytes are retained as `source-icon.svg` (SHA-256
`bf2b2502310b1e7b92cc4f64281f218ba971866d82a0d9a2dfd0c18f90e699d5`).

The local reading views use `../terac-icon.svg`: the same geometry, ivory fill
and even-odd rules, with redundant sizing and inline color declarations removed
for the offline renderer's narrow static SVG subset. A blue tile gives the ivory
mark contrast against the white header. No external asset is loaded at runtime.

The Terac name and mark retain their respective owners' rights. Their inclusion
for Cookbook identification does not grant a general trademark license or
relicense these brand assets under a source-code license.
